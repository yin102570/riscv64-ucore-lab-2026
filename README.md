## 分支与目录约定

一个分支对应一次实验，分支名为 `lab1`、`lab2`……；每条分支顶层只放两个文件夹：

```
labN/
├── code/            # 该实验实现完成后的代码
└── report/
    ├── report.md    # 实验报告，按课程实验报告模板格式
    ├── prompt.md    # 本实验使用过的全部提示词
    └── images/      # 实验报告中引用的测试截图
```

| 分支 | 对应实验（以课程 exercises 文档为准） |
|------|--------------------------------------|
| `lab1` | 中断与异常 |
| `lab2` | 物理内存管理 |
| `lab3` | 虚拟内存管理 |
| `lab4` | 内核线程管理 |
| `lab5` | 用户进程管理 |
| `lab6` | 处理器调度 |
| `lab7` | 同步互斥 |
| `lab8` | 文件系统 |

> 分支名固定为 `labN`；上表实验名称按 ucore 实验的通用划分填写，请与课程 exercises 文档核对后修改。

## 提交方式

1. `git checkout labN` 切到本次实验对应的分支；
2. 把该实验实现完成的代码放进 `code/`；
3. 把 `report.md`、`prompt.md` 与截图分别放进 `report/`、`report/images/`；
4. `git add -A && git commit -m "labN: ..." && git push`。

## 注意

- 仓库必须保持 **public**。
- 不要提交 API Key、访问令牌等凭据。
- `code/` 建议提交该实验完整可编译的工程，而不是仅改动文件；如与助教要求不一致，以助教要求为准。
